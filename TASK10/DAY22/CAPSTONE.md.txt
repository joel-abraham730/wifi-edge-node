- Day 13: MQTT command subscribe + ACK
- Day 19: NVS configuration management
- Day 20: Soak metrics logging

## Data Flow
1. ESP32 boots → loads config from NVS
2. WiFi connect using NVS credentials
3. DHT22 reads temp + humidity (3 retry, median filter)
4. JSON SensorBundle built with schema_version, node_id, fw
5. MQTT publish to zelbytes/lab/92/telemetry (HTTP 202)
6. HTTPS POST backup to /api/iot-lab/v1/telemetry (HTTP 202)
7. Check serial for commands (set_interval, IRRIGATE, STOP)
8. Log SOAK metrics every 75 seconds
9. Repeat every 60 seconds

## Alert Thresholds
- Temperature: 24-30°C (mushroom polyhouse)
- Humidity: 85-92% (mushroom polyhouse)
- WiFi RSSI: > -70 dBm
- Node offline: LWT triggered
