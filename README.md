# WiFi Edge Node
22-day IoT edge telemetry project 
for polyhouse mushroom cultivation 
at Zelbytes Agritech.

## Project Structure
- TASK1/DAY1 - Board setup and identity
- TASK1/DAY2 - Arduino core, USB drivers 
  and build environment setup
- TASK2/DAY3 - WiFi Station Mode and 
  Connection Manager with exponential 
  backoff reconnection
- TASK2/DAY4 - NTP Time Sync and 
  ISO-8601 timestamp formatter
- TASK3/DAY5 - DHT22 temperature and 
  humidity sensor with error handling 
  and median filter
- TASK3/DAY6 - OTA firmware updates 
  with ArduinoOTA and deep sleep snippet

## Board
- DOIT ESP32 DEVKIT V1
- ESP32 WROOM-32D
