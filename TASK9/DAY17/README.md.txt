# Task 12 – CoAP Introduction & Constrained Devices

## Overview

This task focused on understanding the Constrained Application Protocol (CoAP), a lightweight communication protocol designed for constrained IoT devices and low-power networks. The session covered CoAP architecture, message types, resource mapping, comparison with MQTT, and its suitability for battery-powered sensor nodes used in smart agriculture applications.

## Learning Objectives

* Understand CoAP fundamentals and UDP-based communication.
* Learn CON, NON, and OBSERVE message mechanisms.
* Compare CoAP and MQTT for IoT deployments.
* Identify suitable use cases for CoAP in polyhouse monitoring systems.
* Analyze the impact of CoAP on deep sleep power consumption.

* images/ : Screenshots and supporting images.

## Outcome

Successfully studied CoAP communication concepts, evaluated its advantages for low-power IoT deployments, and prepared an integration plan for future deep-sleep sensor implementations.
