# Secrets Hygiene Checklist

## Storage Rules
- secrets.h NEVER committed to Git
- Only secrets.template.h committed (redacted values)
- .gitignore includes secrets.h
- API key stored only in secrets.h locally

## Key Rotation Procedure
1. Go to careers.zelbytes.com → My Instance
2. Click Regenerate API Key
3. Copy new key immediately
4. Update secrets.h on all devices
5. Re-flash all ESP32 nodes with new key
6. Verify HTTP 202 response on first POST
7. Old key is immediately invalidated

## Production Rules
- Remove setInsecure() before production deployment
- Use CA bundle for WiFiClientSecure (setCACert)
- Use MQTTS port 8883 instead of 1883
- Separate API key/token per device
- Rotate keys every 90 days or immediately on suspected leak

## Git Safety Check
Run before every commit:
grep -r "IOT_LAB_KEY" --include="*.ino" .
grep -r "WIFI_PASSWORD" --include="*.ino" .
(Should return no results with real values)
